# Zeus Slot

Браузерный слот на греческую тему по мотивам Ze Zeus. Поле 6×5, выплаты за 8+ одинаковых символов в любом месте, каскады, молнии Зевса, удар кулака с монетами, фриспины и экраны крупного выигрыша BIG / MEGA / SUPER MEGA / EPIC.

Бэкенда пока нет: спины считает локальный мок-движок, который отдаёт тот же контракт, что потом будет отдавать сервер.

## Стек

| Что | Чем |
|---|---|
| UI, панель управления, модалки | Vue 3 (`<script setup>`), SCSS |
| Состояние | Pinia (setup-сторы) |
| Рендер сцены и анимации | PixiJS 8 (WebGL)|
| Звук | Web Audio API |
| Сборка | Vite 8, TypeScript 5.9, vue-tsc |
| Качество кода | ESLint 10, Prettier |

## Быстрый старт

Нужен **Node.js 22+**.

```bash
npm install
npm run dev
```

Игра откроется на http://localhost:5173. Звук включится после первого клика или нажатия клавиши: так требует браузер.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер с горячей перезагрузкой |
| `npm run build` | Проверка типов и продакшн-сборка в `dist/` |
| `npm run preview` | Локальный просмотр собранного `dist/` |
| `npm run typecheck` | Только проверка типов |
| `npm run lint` | ESLint с автоисправлением |
| `npm run format` | Prettier по `src/` |
| `npm run sim -- 500000 balanced` | Прогон мок-движка: RTP, частота фич, максимальный выигрыш. Аргументы: число спинов и профиль (`balanced` / `demo`) |

## Деплой

`npm run build` собирает статический сайт в `dist/`. Его можно положить на любой статический хостинг или отдавать через nginx. Бэкенд для работы не нужен, пока включён мок.

Pixi и Vue собираются в отдельные чанки. Они меняются реже кода игры и между деплоями остаются в кеше браузера.

## Переменные окружения

Задаются в `.env.development` и `.env.production`.

| Переменная | dev | prod | Назначение |
|---|---|---|---|
| `VITE_USE_MOCK_API` | `true` | `true` | `false` переключает на HTTP-бэкенд (`src/api/http.api.ts`) |
| `VITE_API_URL` | пусто | пусто | Адрес бэкенда без `/api`, например `https://api.example.com`. Пусто — тот же домен |
| `VITE_TUNING` | `demo` | `balanced` | Профиль частот, подробнее ниже |
| `VITE_DEBUG` | `true` | `false` | Отладочные параметры URL (см. ниже) |
| `VITE_DEBUG_PANEL` | `true` | `true` | Виджет с FPS и кнопками проверки экранов выигрыша |

### Профили частот

Описаны в `src/config/tuning.config.ts`:

- **`balanced`** — боевые частоты, RTP около 96–97% (проверяется через `npm run sim`);
- **`demo`** — скаттеры и кулак выпадают часто, чтобы быстро проверить фриспины и все баннеры. RTP заведомо выше 100%, для настоящей игры этот профиль не годится.

### Отладочные параметры URL

Работают только при `VITE_DEBUG=true`, на проде выключены.

- `?force=bigwin|freespins|lightning|slam` — крутить, пока не выпадет нужный сценарий;
- `?seed=123` — фиксированный ГПСЧ, чтобы последовательность спинов повторялась;
- `?tuning=demo|balanced` — профиль частот поверх переменной окружения.

## Устройство

```
src/
├── api/            контракт с сервером (types.ts), HTTP-клиент и мок
│   └── mock/       математика спина (engine.ts), ГПСЧ, заглушка бэкенда
├── components/     Vue: канвас, панель управления, меню, таблица выплат
├── composables/    старт игры, позиционирование панели, звук наведения
├── config/         все настройки: сетка, символы и выплаты, тайминги, звуки, частоты
├── game/           всё, что рисует Pixi (Vue не импортирует)
│   ├── core/       твинер, шина событий, загрузчик, звук, easing, общие стили
│   ├── fx/         молнии, ударная волна, кадры молний с неба, вырезка кулака
│   ├── layers/     фон, логотип, рамка, Зевс (мешевая анимация рук и юбки)
│   ├── reels/      поле, колонки барабанов, символы
│   └── presentation/  проигрыватель сценария, экран крупного выигрыша, карточки фриспинов
├── stores/         Pinia: сессия, игровой цикл, интерфейс
└── utils/          форматирование денег, математика
scripts/
├── simulate.ts         прогон движка (npm run sim)
└── key-lightning.ps1   вырезает фон из кадров молний (src/assets/img/lightning)
```
